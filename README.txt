PERSONAL PORTFOLIO WEBSITE — RENZ CEDRICK M. SIKAT
================================================================================

1. PROJECT OVERVIEW
-------------------
This package contains a complete, responsive personal portfolio website designed
for Renz Cedrick M. Sikat, a 1st Year Information Technology student at Mindoro
State University (Calapan City, Oriental Mindoro). The site features a Modern
Dark Mode ("Developer Terminal") aesthetic built with semantic HTML5, CSS3, and
vanilla JavaScript.

2. FILE DESCRIPTIONS
--------------------
- index.html
  The main HTML5 webpage containing the complete portfolio structure (Home,
  About Me, Skills, Certificates & Achievements, Projects, Hobbies & Interests,
  and Contact), accessible navigation, certificate preview modal, and interactive
  JavaScript features.

- style.css
  The external CSS3 stylesheet defining the dark mode color palette (#0F172A,
  #1E293B, #38BDF8, #10B981, #F8FAFC), typography (Inter & JetBrains Mono),
  CSS Grid/Flexbox responsive layouts, hover effects, and scroll animations.

- index_html_code.txt
  An exact plain-text copy of the complete source code in index.html for easy
  viewing, grading, or copying without opening an HTML editor.

- README.txt
  This documentation file explaining the project structure, local usage, and
  GitHub Pages deployment instructions.

3. HOW TO OPEN AND RUN LOCALLY
------------------------------
1. Extract all files from the ZIP archive into a single folder on your computer
   (keep index.html and style.css in the same folder).
2. Double-click `index.html` to open it directly in any modern web browser
   (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari, or Brave).
3. Optional (For Developers): Open the project folder in Visual Studio Code and
   use the "Live Server" extension to preview changes in real time.

4. HOW TO PUBLISH ON GITHUB PAGES
--------------------------------
1. Create a free account or sign in at https://github.com.
2. Click the "+" icon in the top-right corner and select "New repository".
3. Name your repository (for example: `renz-portfolio` or
   `yourusername.github.io`) and set visibility to Public.
4. Click "uploading an existing file" and upload `index.html` and `style.css`
   (ensure `index.html` is in the root directory of the repository).
5. Commit your changes.
6. Go to the repository's "Settings" tab -> select "Pages" from the left
   sidebar.
7. Under "Build and deployment" -> "Branch", choose `main` (and `/ (root)`),
   then click "Save".
8. Wait 1–2 minutes and refresh the page; GitHub will display your live
   portfolio URL!
